# Codex Skills

Reusable skills for Codex workflows.

## Codex Skills

- `daily-ai-brief`: Produces and publishes a ranked Daily AI and Agentic Engineering HTML brief through a bounded, stateful workflow graph with live verification and fail-closed history.
- `luma-event-interest-to-use-case-mapping`: Maps live Luma registration interests to verified official ChatGPT use cases and creates one audience-ready showcase task per ranked theme.
- `orchestrate-projects`: Coordinates long-running, multi-milestone projects through conversational discovery, evidence-gated roadmaps, delegated execution, fresh roadmap audits, and automated specialized review rounds.

Each Codex skill lives in its own folder with a `SKILL.md` entrypoint and any supporting references.
